# موقع فارس علي

موقع تعريفي شخصي عربي باتجاه RTL، مبني بملفات HTML وCSS وJavaScript عادية، ويعمل مباشرة على GitHub Pages من دون خطوات بناء.

## الملفات

- `index.html`: الصفحة الرئيسية ومحتوى الملف الشخصي ومعرض الأعمال.
- `style.css`: التصميم المتجاوب والحركات.
- `script.js`: قائمة متابعة المونتاج، الحفظ المحلي، ومؤثرات الظهور ومؤشر القراءة.
- `sw.js`: تخزين نسخة خفيفة من واجهة الموقع للعمل دون اتصال بعد أول زيارة على HTTPS.
- `404.html`: صفحة الخطأ المخصصة لـ GitHub Pages.
- `robots.txt` و`sitemap.xml`: إرشادات وأساسيات فهرسة الموقع.

## التشغيل

افتح `index.html` في المتصفح، أو انشر محتويات المجلد على GitHub Pages. لا يحتاج المشروع إلى تثبيت حزم أو إعداد قاعدة بيانات. قائمة متابعة المونتاج تحفظ تقدمها محليًا في متصفح الزائر، ويخزّن عامل الخدمة ملفات الواجهة والصورة الأساسية للزيارة دون اتصال على المواقع المنشورة عبر HTTPS. ملفات الفيديو الكبيرة لا تدخل ضمن التخزين المسبق.
